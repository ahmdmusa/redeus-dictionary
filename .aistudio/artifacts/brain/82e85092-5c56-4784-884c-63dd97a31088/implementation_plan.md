# خطة تطبيق نظام تعدين الجمل وتتبع العادات اليومية (Sentence Mining & Daily Habit Streak)

تهدف هذه الخطة إلى إضافة ميزتين رئيسيتين وفقاً لأحدث أساليب تعلم اللغات العالمية (المبنية على أبحاث Reddit r/languagelearning و Anki ومبادئ المدخلات المفهومة Comprehensible Input): **نظام استخراج وتعدين الجمل الواقعية مع النطق الصوتي (Sentence Mining with Audio)**، و**لوحة تتبع العادات وسلسلة الالتزام مع خريطة النشاط التفاعلية (Daily Streak & Habit Activity Heatmap)**، مع التركيز على محتوى المحادثات اليومية والعبارات الإنجليزية الحديثة.

---

## القرارات المعتمدة من المستخدم (User Review & Confirmed Decisions)

> [!IMPORTANT]
> تم اعتماد القرارات التالية بناءً على إجاباتك، وستشكل الركائز الأساسية للتنفيذ:

- **الميزة الأساسية الأولى (Sentence Mining)**: تمكين المستخدم من حفظ وتعدين الجمل الإنجليزية من سياق واقعي متكامل بدلاً من حفظ الكلمات المجردة، مع إبراز الكلمة المستهدفة وسماع النطق الصوتي الكامل للجملة عبر محرك النطق المدمج (TTS).
- **الميزة الأساسية الثانية (Daily Streak & Habit Heatmap)**: توفير لوحة متابعة يومية بارزة تعتمد على خريطة النشاط التفاعلية (على غرار شبكة مساهمات GitHub وخريطة عادات Anki)، تعرض الأيام التي درس فيها المستخدم وكثافة النشاط اليومي (عدد المراجعات والجمل المستخرجة) مع عداد الأيام المتتالية وأعلى رقم قياسي.
- **مستوى المحتوى والتركيز الدراسي**: التركيز التام على **المحادثات اليومية والعبارات الحديثة الشائعة (Everyday Conversation & Practical Modern Phrases)** مثل التعبيرات الاصطلاحية (Idioms)، المحادثات غير الرسمية (Casual Chat / Slang)، عبارات بيئة العمل والمطاعم والتسوق.

## 1. نظرة عامة والمفهوم الأساسي (Overview & Core Concept)

- **ما الذي يقدمه التحديث**:
  1. **مركز استخراج وتعدين الجمل (Sentence Mining Hub)**: يتيح استعراض بنك غني من الجمل الواقعية مقسمة حسب مواقف الحياة اليومية، مع إمكانية تعدين جملة بضغطة زر واحدة من أي بطاقة كلمة في القاموس، أو إضافة جمل مخصصة من محادثات المستخدم الشخصية.
  2. **وضع تدريب الفراغات في الجمل (Sentence Cloze Practice)**: إخفاء الكلمة المفتاحية داخل الجملة الواقعية لاختبار فهم المستخدم لها في السياق، مع زر للكشف عن الكلمة وتشغيل الصوت المسموع للجملة كاملة.
  3. **لوحة العادات وسلسلة الالتزام (Habit Streak Dashboard & Heatmap)**: خريطة مربعات تفاعلية (60 يوماً الأخيرة) تتدرج ألوانها الأخضر والرمادي حسب عدد العمليات التعليمية المنفذة في كل يوم، مع إحصاءات الإنجاز وحماية السلسلة (Streak Freeze / Recovery Indicator).
- **القيمة الأساسية للمتعلم**:
  - الانتقال من الحفظ السلبي للكلمات المنفصلة إلى الاكتساب الطبيعي للغة عبر السياق (i+1 Comprehensible Input).
  - تعزيز عادة الاستمرارية اليومية من خلال رؤية التقدم البصري المباشر على خريطة النشاط.
  - جاهزية فورية للتحدث باللغة الإنجليزية في مواقف الحياة اليومية الحقيقية.

## 2. تجربة المستخدم والتصميم البصري (User Experience & Visual Design)

### الهوية البصرية (Neo-Brutalist Design System)
تستمر جميع الإضافات الجديدة بذات الهوية البصرية الجريئة والمميزة للتطبيق:
- **الألوان والتناغم**:
  - خلفيات نظيفة بلون كريمي/أبيض دافئ (`NeoCream` / `NeoWhite`) مع إطارات سوداء صلبة (`2.dp` إلى `2.5.dp`).
  - ألوان مميزة بارزة: أصفر نيو-بروتاليست (`NeoYellow`) للتبويبات والأزرار النشطة، أخضر نيو-بروتاليست (`NeoGreen`) لمربعات النشاط وسلاسل الأيام المكتملة، أحمر نيو-بروتاليست (`NeoRed`) لشارات اللهب (`🔥 Streak Badge`) والتنبيهات، وسماوي (`NeoCyan`) لوسوم فئات المحادثات.
- **الخطوط ومناطق اللمس**: عناوين سميكة بحروف واضحة، وأزرار تفاعلية بارتفاع لا يقل عن `48.dp` تضمن تجربة استخدام سريعة ومريحة مع تأثيرات النقر الفورية.

### تدفقات المستخدم الرئيسية (Key User Flows)

1. **تدفق تعدين الجمل واستعراضها (Sentence Mining & Library)**:
   - في تبويب **LIBRARY** أو من خلال قسم مخصص **SENTENCE MINING**:
     - شريط تصنيفات أفقي لاختيار سياق المحادثة: `ALL`, `CASUAL CHAT`, `WORKPLACE`, `DINING & COFFEE`, `ERRANDS & TRAVEL`, `IDIOMS`.
     - بطاقات جمل بتصميم نيو-بروتاليست أنيق: تظهر الجملة بالإنجليزية مع إبراز الكلمة المستهدفة بخلفية صفراء خفيفة وخط عريض، وتحتها الترجمة/المعنى السياقي.
     - زر نطق صوتي فوري للجملة (`🔊 Listen Sentence`) عبر محرك النطق المدمج.
     - زر المفضلة والإتقان لتحديد الجمل المتقنة.
   - **تعدين فوري بضغطة واحدة من القاموس (One-Tap Mine from Dictionary)**: عند البحث عن أي كلمة في تبويب `SEARCH` أو تصفح بطاقات `CARDS`، يظهر زر `⛏️ MINE SENTENCE` يضيف مثال الكلمة فوراً إلى بنك الجمل المستخرجة مع إشعار نجاح (Toast/Snackbar).
   - **إضافة جملة مخصصة (Custom Sentence Miner)**: نافذة سريعة تتيح للمستخدم لصق أي جملة سمعها في فيديو يوتيوب أو قرأها في مقال، وتحديد الكلمة الجديدة فيها ومعناها لتخزينها فوراً.

2. **تدفق تدريب الجمل بالسياق (Sentence Cloze Review Mode)**:
   - وضع تدريبي سريع داخل قسم الجمل:
     - تُعرض الجملة مع إخفاء الكلمة المفتاحية في فراغ مظلل `[  _____  ]`.
     - يفكر المتعلم في الكلمة الملائمة للسياق، ثم يضغط `REVEAL KEYWORD`.
     - يتم كشف الكلمة وتشغيل الصوت التلقائي للجملة بصوت واضح، مع خياري تقييم: `GOT IT` أو `REVIEW AGAIN` لتحديث مستوى التدريب.

3. **تدفق متابعة سلسلة الأيام وخريطة النشاط (Daily Habit Streak & Activity Heatmap)**:
   - يتم إبراز بطاقة النشاط اليومي في أعلى شاشات التطبيق الرئيسية (شاشة المكتبة والمراجعة):
     - **شارة السلسلة الحالية**: تعرض عدد الأيام المتتالية بنمط نار بارز (`🔥 5 DAYS STREAK`) مع أعلى رقم قياسي محقق (`🏆 Longest: 12`).
     - **مصفوفة النشاط (Interactive Heatmap Grid)**: مصفوفة مربعات تمثل آخر 60 يوماً مقسمة لأسابيع (مثل GitHub Contribution Graph):
       - رمادي فاتح: بدون نشاط (0 عمليات).
       - أخضر باهت: نشاط خفيف (1 إلى 4 مراجعات أو جمل).
       - أخضر متوسط: نشاط جيد (5 إلى 12 مراجعة أو جملة).
       - أخضر فاقع/أصفر نيو-بروتاليست: نشاط مكثف (13+ مراجعة).
     - عند النقر على أي مربع في الخريطة، تظهر تفاصيل التاريخ وعدد الجمل والمراجعات المنجزة فيه.
     - مؤشر هدف اليوم: شريط تقدم بسيط (`Today's Goal: 4/10 Actions`) يشجع المتعلم على إتمام هدفه اليومي.

## 3. القرارات الهندسية والمفاضلات (Key Product Decisions & Trade-Offs)

- **القرار 1: استخدام جدول مخصص في قاعدة البيانات المحلية Room (`mined_sentences`) مع ترقية آمنة (`MIGRATION_11_12`)**
  - *لماذا*: يتيح حفظ مئات الجمل مع بياناتها وسياقها المستقل وسرعة استعلام عالية دون التأثير على جدول الكلمات الأساسي أو إبطاء عمليات المراجعة والتكرار المتباعد الحالية.
- **القرار 2: دمج النطق الصوتي للجمل عبر محرك TextToSpeech الحالي في ViewModel**
  - *لماذا*: محرك TTS المهيأ مسبقاً في التطبيق لا يتطلب استهلاك شبكة أو مفاتيح API مدفوعة، ويستطيع نطق الجمل الإنجليزية الطويلة بسرعة وسلاسة مع ضبط السرعة ونبرة الصوت المناسبة للمتعلم.
- **القرار 3: حساب خريطة النشاط (Heatmap) بناءً على سجل العمليات التراكمي الشامل**
  - *لماذا*: بدلاً من الاقتصار على بطاقات المراجعة (SRS)، سيتم احتساب كل تمرين جملة (Sentence practice)، مراجعة بطاقة، أو جلسة قراءة يومية، مما يحفز المستخدم على التفاعل مع التطبيق بأي وسيلة يفضلها ويمنع فقدان السلسلة طالما قام بنشاط تعليمي حقيقي.
- **القرار 4: حزم بنك بيانات أولي غني للعبارات اليومية الأكثر شيوعاً (Seed Pre-mined Everyday Sentences)**
  - *لماذا*: يضمن حصول المستخدم على قيمة فورية بمجرد تشغيل التحديث دون الحاجة للبدء من شاشة فارغة، ويغطي مواقف التحدث الواقعية الشائعة.

### تفاصيل الكيانات وقاعدة البيانات (Room Schema)

```kotlin
@Entity(tableName = "mined_sentences")
data class MinedSentenceEntity(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val sentence: String,
    val targetWord: String,
    val meaning: String,
    val category: String, // "Casual", "Workplace", "Dining", "Idioms", "Travel"
    val notes: String = "",
    val isFavorite: Boolean = false,
    val practiceCount: Int = 0,
    val lastPracticed: Long? = null,
    val timestamp: Long = System.currentTimeMillis()
)
```

### ترقية قاعدة البيانات (Database Migration v11 to v12)
```kotlin
private val MIGRATION_11_12 = object : Migration(11, 12) {
    override fun migrate(db: SupportSQLiteDatabase) {
        db.execSQL("""
            CREATE TABLE IF NOT EXISTS `mined_sentences` (
                `id` INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
                `sentence` TEXT NOT NULL,
                `targetWord` TEXT NOT NULL,
                `meaning` TEXT NOT NULL,
                `category` TEXT NOT NULL,
                `notes` TEXT NOT NULL DEFAULT '',
                `isFavorite` INTEGER NOT NULL DEFAULT 0,
                `practiceCount` INTEGER NOT NULL DEFAULT 0,
                `lastPracticed` INTEGER DEFAULT NULL,
                `timestamp` INTEGER NOT NULL
            )
        """.trimIndent())
    }
}
```

## 5. خطة التحقق والاختبار (Verification Plan)

1. **التحقق من سلامة البناء والتوافق البرمجي**:
   - تشغيل أداة الفحص `compile_applet` للتأكد من خلو المشروع من أخطاء الـ Gradle ومطابقة ترقية قاعدة البيانات Room.
2. **التحقق من ميزة Sentence Mining**:
   - التأكد من إدراج واسترجاع الجمل المجهزة مسبقاً وتصنيفها بدقة.
   - التحقق من عمل زر النطق الصوتي للجملة وتشغيل الصوت بوضوح عبر `TextToSpeech`.
   - اختبار زر استخراج الجملة من بطاقة الكلمة وحفظها بنجاح داخل قاعدة البيانات.
   - اختبار وضع تدريب الفراغات (Cloze Mode) والتحقق من كشف الكلمة وتحديث عداد التدريب.
3. **التحقق من خريطة النشاط وسلسلة الأيام (Streak & Heatmap)**:
   - التأكد من تحديث عداد النشاط عند إتمام أي عملية مراجعة أو تمرين جملة.
   - التأكد من رسم مربعات الـ 60 يوماً وتدرج الألوان بشكل صحيح حسب كثافة النشاط.
   - التأكد من حفظ السلسلة واستعادتها بشكل دقيق بين جلسات فتح التطبيق.
